# Gacha Story Glass · 스토리 투명화

Marinara Engine 2.5.0 / Gacha Forge 1.8.12용 별도 개인 확장입니다.

**v1.2.1**은 v1.1.0의 홈 배경 확장 방식과 최근 사용한 **스토리 40% / 홈 30% 투명도**를 유지하면서 기본 버튼에만 스타일을 적용하고 화면 탐색을 줄인 버전입니다.

- 홈에서 통신·배경 선택·인물 선택 팝업을 열면 상단 바에도 흐림·어둡기 효과를 표시합니다. 팝업 아래만 흐려지고 위쪽이 선명하게 남던 문제를 수정했습니다. 닫으면 원래 상단 바 스타일로 돌아옵니다. 이 효과는 클릭을 가로채지 않고 이미지나 버튼 배치를 변경하지 않습니다.

- 상단 바에서 가챠포지 기본 버튼·재화·랭크 영역만 지정합니다. 다른 확장이 추가한 일반 버튼에는 스타일을 덮어쓰지 않습니다. 클릭·키보드 이벤트를 가로채거나 버튼을 추가하지 않습니다.
- 상단 바 높이가 바뀔 때는 현재 바만 측정합니다. 화면 전체를 다시 찾지 않으며, 다른 확장 버튼이나 카운터가 바뀌어도 홈·상단 바를 재탐색하지 않습니다.
- `ResizeObserver`를 사용할 수 있으면 별도의 전역 화면 크기·전체 화면 이벤트를 구독하지 않습니다. 확장을 끄면 추가한 스타일·관찰자·CSS 변수만 정리합니다.

## GitHub에서 설치·업데이트

마리나라의 GitHub 가져오기에 다음 저장소 주소를 입력하세요.

https://github.com/lemonpie601/gacha-glass

기본 브랜치 `main`의 루트에 `manifest.json`과 `extension.js`를 배치합니다. 기존 확장을 삭제하지 말고 업데이트·GitHub 연결 기능으로 가져오세요. 확장 이름과 `runtime`은 기존 ZIP과 동일하며, 업데이트 후에는 마리나라에서 새 코드를 검토하고 실행해야 합니다.

- 스토리 배경 위쪽 비네트와 대사창 뒤에 겹친 아래쪽 어두운 막을 제거합니다.
- 홈 배경의 비네트와 인물 카드에 겹친 어두운 막도 제거합니다.
- 홈 상단 바·홈 버튼 배경은 **30% 투명 / 70% 불투명**으로 표시합니다. 스토리 대사창은 기존 **40% 투명 / 60% 불투명**을 유지합니다. 배경 블러와 겹치는 패널 그림자도 제거합니다.
- 홈의 이벤트·업적·전투·하단 메뉴·편지·배경 변경 버튼과 상단의 재화·설정 등 버튼에 적용합니다. 키보드 초점 표시는 유지합니다.
- 상단 바 뒤까지 홈 배경을 이어 붙여, 투명한 바 아래로 실제 배경이 보이게 합니다. 상단 바 높이에 맞춰 배경만 확장하며 버튼 위치와 클릭 영역은 유지합니다.
- 대사 글자·아이콘·인물 그림 자체를 흐리게 하지 않습니다. 스토리 이름표와 버튼 동작도 유지합니다.
- 일반 화면과 전체 화면에 같은 스타일을 적용합니다. 홈을 떠나면 다른 화면의 상단 바와 버튼은 원래 스타일로 표시합니다.
- 설정 버튼을 추가하지 않습니다. 확장을 끄면 원래 화면으로 돌아갑니다. 의상 테마 관리 확장과 함께 사용할 수 있습니다.

## 설치

1. 마리나라의 **설정 → 애드온 → 외부 확장**에서 파일 가져오기를 엽니다.
2. `gacha-story-glass-1.2.1.personal-extension.zip`을 가져옵니다. 기존 확장을 사용 중이면 삭제하지 말고 같은 이름으로 가져와 업데이트하세요.
3. 확장 이름이 **Gacha Story Glass · 스토리 투명화**인지 확인하고 코드를 검토한 뒤 실행합니다. 기존 의상 관리 확장을 교체할 필요가 없습니다.
4. 가챠포지 홈 화면과 스토리에 바로 적용됩니다.

게임의 Shadow DOM에 스타일을 넣기 위해 `full_page_access` 권한을 사용합니다. API 요청, 데이터 저장, 게임 파일 변경은 하지 않습니다. 실행 중 확장을 다시 켜도 스타일을 중복 삽입하지 않으며, 비활성화할 때 다른 확장의 스타일을 제거하지 않습니다.

스타일은 JS에 포함되어 있습니다. 전역 CSS로는 게임의 Shadow DOM에 접근할 수 없으므로 별도 `cssPath`는 없습니다. 빌드나 의존성 설치 없이 바로 실행할 수 있습니다.

설치된 가챠포지의 스토리·홈·상단 바 스타일과 화면 구조를 대조하고, 적용·재실행·화면 재생성·상단 바 높이 변경·홈 화면 이탈·정리 동작을 자동 테스트로 확인했습니다. 실제 앱 화면의 시각 검증은 수행하지 못했습니다.

테스트: `node --test tests/story-glass.test.cjs`

## 투명도 직접 수정

`extension.js`의 `.vn .vn-box`에서 `0.6`과 `60%`는 스토리 배경의 불투명도입니다. `.hm-screen .hm-tile`로 시작하는 홈 영역에서 `0.7`과 `70%`는 홈 배경의 불투명도입니다. 각 영역의 두 숫자를 함께 변경하세요. 예를 들어 50% 투명은 `0.5` / `50%`입니다. 수정본을 배포할 때는 매니페스트의 `config.version`을 올리되 `config.name`과 `runtime`은 유지하세요.
